## `$ ls features/`

- Typing animation in hero section
- Active nav link on scroll (IntersectionObserver)
- Responsive hamburger menu
- CRT / scanline overlay effect
- Accessible — skip link, ARIA labels, focus styles, reduced motion support
- Deployed on Vercel
